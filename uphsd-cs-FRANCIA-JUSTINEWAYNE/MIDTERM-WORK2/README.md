This program reads a CSV dataset after asking the user to provide the file path.
For MP05, it lets the user choose a column and prints all non-empty values from that column.
For MP11, it counts how often each value appears in a selected column and displays the frequency in a clear format.
For MP18, it removes rows that contain empty fields, shows how many rows were removed, and can save cleaned rows to a new CSV file.
Both Java and JavaScript versions follow the same logic and produce equivalent results.
